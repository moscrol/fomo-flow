# dao-proxy-pro 9.9.396 发布说明

本版本修复 Devin 已注册项目工作区，但模型在后续搜索调用中只传 `Scripts` 等相对路径时，原生搜索执行器报 `Cannot search path ... outside a currently open workspace` 的问题。

## 修复方式

- 保留 Devin 原生 `grep_search`、`find_by_name`、`CodeSearch` 与 `smart_reading` 执行器，不替换搜索实现。
- ACP 注册的当前工作区根同步到扩展宿主内的路由器。
- 仅当搜索工具参数是相对目录时，在发给 Devin 前修正路径。
- 优先使用同一对话最近一次有效搜索目录。例如先搜索 `E:\项目\Assets`，随后传入 `Scripts`，会解析为 `E:\项目\Assets\Scripts`。
- 最近目录无法解析时，尝试当前 ACP 工作区根；仍无法解析时进行最多 25ms、最多 600 个目录的浅层唯一匹配。
- 多个同名目录时不猜测，保留原参数交给 Devin 返回明确错误。
- 合法绝对路径、读取/编辑/终端等非搜索工具保持逐字不变。

## 性能

- 正常绝对路径走常数时间快路径，不访问目录树。
- 本机基准为 100,000 次绝对路径归一化约 190ms，单次约 0.0019ms。
- 只有模型传入无法直接解析的错误相对路径时才触发浅层查找，硬上限 25ms；不会增加模型网络请求或等待一次原生失败后再重试。

## 验证

- 相对路径按最近搜索目录解析。
- 相对路径按工作区根解析与唯一浅层目录发现。
- 同名目录歧义时不改写。
- `search_folder_absolute_uri` 正确生成 `file:///` URI。
- 首次流式、非流式及内部工具续跑均携带相同工作区上下文。
- 工作区策略、原生工具契约、缓存、自定义模型、协议中转和 Webview 回归全部通过。
- 全链路快速测试：307 项通过，0 项失败。
