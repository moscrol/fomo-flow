# dao-proxy-pro 9.9.397 发布说明

本版本在 `9.9.396` 的 Devin 原生搜索相对路径修复基础上，补全多根 `.code-workspace` 的项目消歧。

## 单项目与窗口切换

- 每次启动 ACP 时读取当前 Devin 窗口的 `workspaceFolders`，不会固定保存某个项目路径。
- 不同 Devin 窗口由不同扩展宿主进程管理，各自持有自己的工作区根。
- 当前窗口没有文件工作区时，主动清除旧根目录，避免沿用上一个项目。

## 多根工作区

- 主文件夹作为 ACP `cwd`，其余文件夹通过 `additionalDirectories` 一并注册。
- 相对搜索路径优先按同一对话最近一次有效搜索目录解析。
- 没有最近目录时，仅当全部工作区根中只有一个目录匹配才自动补全。
- 多个项目都含同名目录时不猜测、不默认选第一个根，保留参数交给 Devin 原生执行器报告明确错误。
- 使用绝对路径时不进行任何改写。

## 验证

- 单根相对路径补全通过。
- 多根唯一命中通过。
- 多根同名目录保持不变通过。
- 最近项目目录可正确消歧通过。
- ACP 工作区注册与工作区搜索策略集成测试通过。
