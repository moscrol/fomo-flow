# Dao Flow 导航收口设计

- 状态：进入 P1 执行
- 目标：默认导航先回答“现在做什么、请求怎么走、如何协作”，把低频连接细节收进高级连接。

## 信息架构

1. **工作台**：当前工作、首页、实时情况、问题与数据。
2. **路由配置**：接入渠道、模型怎么走、自定义模型、系统提示词。
3. **协作与交接**：协作会话、任务进度、Codex 连接。
4. **高级连接**：本地接口、远程访问、接口兼容、外部接入。

只改变导航分组与直白文案，不删除功能、不更改 view ID、深链、接口或业务状态。高级连接默认折叠，但当前活动视图属于该组时自动展开；用户可手动展开，状态只存在当前 React 会话。

## 边界与验收

- 不新增 endpoint、IPC、远程服务或自动连接动作。
- 不改变路由 priority 或任何配置值。
- 键盘/命令面板仍可到达所有旧视图，合法持久化 view 继续恢复。
- 测试覆盖分组顺序、默认折叠、活动视图自动展开、手动展开、所有旧视图可达。
